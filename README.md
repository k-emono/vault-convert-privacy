# vault-convert（個人用）

このアプリは、自分の Google ドライブ上の Obsidian Vault にあるドキュメントを読み取り、手元の Windows で Markdown に書き出す個人用ツールです。

## 利用する Google データ

- Google ドライブの読み取り専用（ドキュメント・スプレッドシート・スライドの本文取得）

## データの扱い

- 取得した本文は、自分の Obsidian Vault 内の `.md` として保存する
- 第三者への販売・広告利用・モデル学習への提供はしない
- 認証トークンは Google ドライブ外の PC 内（`%APPDATA%\vault-convert`）にだけ置く
